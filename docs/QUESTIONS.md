# QUESTIONS

사용자 결정 없이는 진행할 수 없는 현재 항목만 기록한다. §14에서 기본값이 정해진 항목은 기본값으로 계획하며, 실제 정지 조건이 되기 전에는 질문으로 올리지 않는다.

## 상태 표기

- `OPEN`: 답변 전이며 `멈춘 단계/작업`에 적힌 범위만 중지
- `ANSWERED`: 답변과 날짜를 기록하고 관련 계획·결정을 갱신
- `SUPERSEDED`: 후속 결정으로 대체

## 열린 질문

### Q-001 — Phase 1 실기기 검증 대상

- 날짜: 2026-08-20
- 상태: OPEN (Android 결정 완료, 기기 식별 정보만 미기록)
- 관련 명세: §7, §10.3, §11 AC-1·AC-13·AC-14, §14
- 멈춘 단계/작업: 없음. Android development APK와 tunnel을 사용해 Phase 1 실기기 게이트를 진행한다. 기기 모델·Android 버전은 증빙 메타데이터에 기록할 때 확인한다.
- 필요한 결정: Phase 1에서 실제 설치·알림·콜드 스타트 딥링크를 검증할 사용자 휴대폰의 OS, 기기 모델, OS 버전. iPhone만 사용할 경우 AC-14의 Android 개발 빌드 검증에 사용할 수 있는 Android 기기 또는 별도 검증 방법도 필요하다.
- 선택지와 영향:
  - Android 실기기: AC-1·AC-13·AC-14를 같은 기기에서 검증할 수 있다. 현재 기본 제안이다.
  - iPhone 실기기: AC-1·AC-13은 iPhone에서 검증하고, AC-14는 Android 개발 빌드에서 별도로 검증해야 한다.
  - 두 OS 실기기: 양쪽 설치·알림 경로를 검증할 수 있으나 수동 검증 범위가 늘어난다.
- 에이전트 기본 제안: 사용 가능한 Android 실기기를 Phase 1 주 검증 대상으로 지정하고, iOS는 개발 빌드 준비까지만 수행한다. 실제 보유 기기가 다르면 그 기기를 우선한다.
- 결정 전 임시 조치: Android를 Phase 1 주 검증 대상으로 사용하고 iOS 검증·Phase 2 착수는 하지 않는다.
- 사용자 답변: 2026-08-23 Android development APK 설치, 아이콘 실행, Metro tunnel 연결과 Android bundle 수신을 확인했다. 기기 모델·Android 버전은 아직 미기록이다.

## 현재 질문으로 올리지 않은 §14 항목

- 주 시작 요일, 하루 종료 시각, 알림 시각, 초기 시드, 앱 이름·아이콘은 §14 기본값으로 시작할 수 있어 현재 결정이 필요하지 않다.
- Supabase·인증은 Phase 2, Telegram 자격증명은 Phase 3, AI 제공자·키는 Phase 4 착수 전에 질문한다.
