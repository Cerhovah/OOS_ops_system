# 레퍼런스·MCP 예산 원장

규범은 [SPEC §21](SPEC.md). 2026-09-06 사용자 답변: **Mobbin·Figma·관련 MCP 레퍼런스 조사와 설계 전달에만 총 80,000원**. 월간 예산이 아니며 실제 청구는 결제 시 확인한다.

## 현재 잔액

- 이번 명세 세션 확정 지출: **63,000원** (사용자 결제 완료 확인)
- 계획 시작 이후 기록된 누적 지출: **63,000원**
- 명세상 잔액: **17,000원**
- 자동 갱신: Mobbin Pro 분기 구독의 갱신 해제 여부는 확인하지 않았다. 다음 갱신 전 계속 사용할지 사용자가 결정한다.

## 배정안 — 결제 가격이 아닌 상한

| 용도 | 배정 | 근거 / 집행 시점 |
|---|---:|---|
| Mobbin | 실제 63,000원 | Pro 3개월. Tiimo 핵심 flow 확인과 P5 주 레퍼런스 결정에 사용 |
| Figma | 잔여 상한 17,000원 | Starter에서 합성 데이터 4화면 capture 완료. 현재 추가 결제 불필요 |
| 합계 | **80,000원** | 배정은 소비/결제 승인 실행 결과가 아님 |

Google Play 등록, EAS, Supabase, 도메인, SMTP, AI 사용료는 이 예산에 포함하지 않는다. 그런 비용이 실제로 필요하면 별도 근거·금액·사용자 승인을 먼저 기록한다. 무료 기능으로 충분하면 지출은 0원이며, 유료 구독은 자동 갱신을 해제한다.
