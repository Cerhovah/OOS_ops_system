## 실기기 핵심 흐름

- 동기화를 의도적으로 실패시키는 로컬 개발 URL을 프로세스에만 주입해 원격 데이터를 바꾸지 않았다. `.env.local`과 EAS 환경은 수정하지 않았다.
- 앱 전용 `files/SQLite/oos-ops.db`, WAL, SHM을 앱 캐시에 먼저 복사하고 원본/백업의 크기와 SHA-256 일치를 확인한 뒤 임시 시나리오를 실행했다.
- 기존 실행 중인 `통학`은 검증 원본 상태에서 직접 종료하지 않았다. 백업된 임시 상태에서만 종료한 뒤 `오늘의 할일 확인 → 할일 추가 → 운동 선택 → 시작 → 종료`를 확인했다.
- `직접 기록 → 운동 → 15분 → 기록 저장 → 기록 원장`을 확인했고, 오늘/어제/날짜 선택 내비게이션과 과거 날짜의 오늘 전용 행동 비노출을 확인했다.
- TaskSheet는 접근성 트리에서 스크롤 가능한 목록, 48dp 이상 행/버튼, 닫기·할일 추가·직접 기록 라벨을 제공했다. 200% 글꼴에서 실행 화면의 핵심 정보와 `종료하고 기록` 버튼이 탭 가능한 상태임을 확인하고 기기 글꼴 배율을 원래 1.15로 즉시 복구했다.
- 앱을 정지한 뒤 SQLite 원본 세 파일을 백업본으로 정확히 복원했고 세 SHA-256이 다시 일치했다. 재실행 화면에서 기존 `통학` 타이머가 계속 측정 중임을 확인했다. 임시 백업과 ADB UI dump는 이후 정확한 파일명으로 제거했다.
